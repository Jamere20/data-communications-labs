# Data Communications Assignments & Exams

## Overview
This repository contains assignments, labs, projects, and exam materials completed for my Data Communications course. The coursework focuses on networking fundamentals, data transmission, communication protocols, network models, and cybersecurity-related communication concepts.

## Topics Covered
- Network Fundamentals
- OSI Model
- TCP/IP Protocol Suite
- Data Transmission
- Network Topologies
- IP Addressing & Subnetting
- Routing & Switching Concepts
- Wireless Communications
- Error Detection & Correction
- Network Security Basics

## Technologies Used
- Cisco Packet Tracer
- Wireshark
- Networking Tools
- Python
- Git & GitHub
